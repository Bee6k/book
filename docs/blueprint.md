# **App Name**: LitLink

## Core Features:

- Book Listing: Displaying list of books with filtering based on genre.
- Book Detail: Display book cover, title, author and format options.
- Theme Toggle: Implementing a dark/light mode toggle.

## Style Guidelines:

- Primary color: Dark background (#111 or similar) with light gray/white text
- Accent: Teal (#008080) for buttons and highlights.
- Subtle animations when switching modes.
